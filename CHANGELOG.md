# Changelog

All notable changes to the "ACS Schema Support" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-02-01

### Added

- Initial release
- YAML schema validation for Certificate Profile (`*.certprofile.yml`) files
- YAML schema validation for CA Profile (`*.caprofile.yml`) files
- YAML schema validation for Keystore (`*.keystore.yml`) files
- IntelliSense, autocompletion, and hover documentation for all supported file types
